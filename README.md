# Shuwaikh Almashatil Nurseries Website

A fresh, bilingual single-page application concept for a plant nursery and landscaping business in Kuwait.

## Live preview

https://shahinalambd.github.io/shuwaikh-nurseries-website/

## Key features

- English / Arabic with full RTL support
- Hash-based routing: plants, seasonal, gallery, care guides, FAQ, services and contact
- Plant catalogue with categories, filters, product pages and an enquiry list
- Care guide articles and grouped FAQ
- Live "open now" status based on Kuwait time
- Contact and wholesale forms with client-side validation
- Optimised responsive WebP images

## Tech used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts
- No build step, so the site runs as plain static files

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- All contact details are placeholders (`+000 0000 0000`, `hello@example.com`).
- Forms are static demos: they validate input but do not send any data.
